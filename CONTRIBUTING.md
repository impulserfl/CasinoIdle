# Contributing to CasinoIdle

Thanks for your interest in the project!

## How to Contribute

1. Fork the repository
2. Create a new branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Commit with a clear message
5. Open a Pull Request

## Code Style

- Use tabs for indentation in GDScript (see `.editorconfig`)
- Keep scripts focused and readable
- Prefer clear variable/function names over short ones

## Reporting Issues

Please use the issue templates when reporting bugs or requesting features.

## Questions?

Feel free to open an issue with the question tag or start a discussion.
